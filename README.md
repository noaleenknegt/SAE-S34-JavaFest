# Site de la JavaFest
Projet de groupe universitaire en VueJS, NodeJS et mariaDB

Non exécutable pour le moment.

## Lancer le projet
Tout s'éxécute depuis la racine du projet<br>
Base de données :
```bash
cd backend
mariadb -u VOTRE_NOM_D_UTILISATEUR_MARIADB --host=L_HOTE_DE_VOTRE_BASE_DE_DONNEES -p
```
```mariadb
use BASE_DE_DONNEES_DU_PROJET;
source init.sql;
```

Frontend : 
```bash
cd fontend
npm install
npm run build
```

Backend :
```bash
cd backend
npm install
npm run start
```
